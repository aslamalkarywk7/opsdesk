# Dashboard Design Gallery (65 variants)

Public page `/showcase`: 8 domains x 8 layout systems + 1 signature = 65 live previews.
Every card opens a full themed workspace at `/showcase/[id]` (sidebar, stats, chart, table in that design's tokens). Each workspace is interactive: live search, status filter chips with counts, sortable columns, pagination. Unknown ids return 404.

## What it proves to hiring managers

- **Range:** Healthcare, Finance, E-commerce, Education, Logistics, HR, Real Estate, SaaS - you adapt UI language per business.
- **Systems thinking:** 8 named layouts (Executive, Compact Ops, Night Shift, Minimal, Data Dense, Card Wall, Timeline, Split Command) - you design with reusable patterns, not one-offs.
- **Token discipline:** every variant is driven by palette + nav + chart + density tokens in `lib/designs.ts` - the skill behind design systems.
- **Responsive density:** airy / compact / dense modes show you design for wall screens and old laptops alike.
- **Accessibility awareness:** dark and light themes with distinct accent/muted roles.
