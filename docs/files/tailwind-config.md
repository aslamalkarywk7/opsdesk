# `tailwind.config.ts`

> Design tokens: brand/ink colors, card shadow, content globs.

## What it does

- Scans `app/**/*.{ts,tsx}` + `components/**/*.{ts,tsx}` for utilities.
- Extends `brand` (blue) + `ink` (slate) palettes, `card` shadow, `xl2` radius.
- Per-design gallery tokens live in `lib/designs.ts`.
